Behavior details

Paths
Paths are resolved with FormGroup.get(). Examples: profile.name and addresses.0.street. A missing path fails the assertion.
ValidatorFn
toHaveValidator and toHaveValidators use hasValidator(), which compares function references. Store and reuse the ValidatorFn instance assigned to the control.
hasError()
Error matchers use hasError() against the current validation state. They do not trigger validation themselves.
value / rawValue
toHaveFormValue compares form.value, which omits disabled controls. toHaveRawValue uses getRawValue() and includes them. Jest performs deep equality.
.not
Standard Jest negation works too: expect(form).not.toBeValidForm().
