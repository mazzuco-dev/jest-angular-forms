Usage examples

Paths follow AbstractControl.get() syntax, including nested groups and FormArray indexes.

Nested controls and FormArray

const form = new FormGroup({
  profile: new FormGroup({ name: new FormControl('', Validators.required) }),
  addresses: new FormArray([
    new FormGroup({ street: new FormControl('', Validators.required) }),
  ]),
});

expect(form).toHaveControls('profile.name', 'addresses.0.street');
expect(form).toHaveRequiredControls(['profile.name', 'addresses.0.street']);

Values and disabled controls

const form = new FormGroup({
  email: new FormControl('ada@example.com'),
  id: new FormControl({ value: 42, disabled: true }),
});

expect(form).toHaveFormValue({ email: 'ada@example.com' });
expect(form).toHaveRawValue({ email: 'ada@example.com', id: 42 });
expect(form).toHaveDisabledControl('id');

Errors and validators

const minLength = Validators.minLength(8);
const password = new FormControl('short', { validators: [minLength] });
const form = new FormGroup({ password });

expect(form).toHaveValidator('password', minLength);
expect(form).toHaveControlError('password', 'minlength');
expect(form).toBeInvalidForm();
