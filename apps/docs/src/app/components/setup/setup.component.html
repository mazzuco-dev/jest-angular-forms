Installation and configuration

Install the package as a development dependency in the project running the tests.

1. Install

npm install --save-dev @mazzuco-dev/jest-angular-forms

2. Register matchers

src/test-setup.ts
import { setupZonelessTestEnv } from 'jest-preset-angular/setup-env/zoneless';
import { registerAngularFormMatchers } from '@mazzuco-dev/jest-angular-forms';

setupZonelessTestEnv();
registerAngularFormMatchers();

3. Configure Jest

jest.config.ts
export default {
  setupFilesAfterEnv: ['<rootDir>/src/test-setup.ts'],
};

Include the setup file in tsconfig.spec.json as well so TypeScript can see the matcher declarations. If your tests use Zone.js, initialize that environment before calling registerAngularFormMatchers().
