API reference

Matchers return an assertion result with a failure message and support .not. Methods taking multiple paths accept strings and arrays of strings.

Structure and state

Matcher Behavior
toHaveControl(path) The control exists at the given path.
toHaveControls(...paths) All specified controls exist.
toHaveEnabledControl(path) The control exists and is enabled.
toHaveDisabledControl(path) The control exists and is disabled.

Validation

Matcher Behavior
toHaveRequiredControl(path) The control has Validators.required.
toHaveRequiredControls(...paths) All controls have Validators.required.
toHaveValidator(path, validator) The control has the same ValidatorFn reference.
toHaveValidators(path, ...validators) The control has all ValidatorFn references.
toHaveControlError(path, error) The control has the error in its current state.
toHaveControlErrors(path, ...errors) The control has all errors in its current state.
toHaveFormError(error) The FormGroup has the error in its current state.
toBeValidForm() The FormGroup is valid.
toBeInvalidForm() The FormGroup is invalid.

Values

Matcher Behavior
toHaveControlValue(path, expected) Deeply compares a control value.
toHaveFormValue(expected) Deeply compares form.value.
toHaveRawValue(expected) Deeply compares form.getRawValue().
